# Центр Притяжения — PWA

Цифровое пространство сообщества «Центр Притяжения» (Асбест).

## Текущий этап
Первый интерфейсный каркас: адаптивная главная страница, навигация-заготовка и PWA manifest через Vite PWA.

## Требования
- Node.js 20.19+ или 22.12+
- npm

## Запуск локально
```bash
npm install
npm run dev
```

## Проверка production-сборки
```bash
npm run build
npm run preview
```

## Структура
```text
src/
  App.tsx       Главный интерфейс
  main.tsx      Точка входа React
  styles.css    Адаптивные стили
public/         Статические ресурсы и будущие изображения
```

## Принципы продукта
- Теплота, бережность и безопасность.
- Просмотр основных разделов без регистрации.
- Минимальный сбор персональных данных.
- Реальные фотографии добавляются только после согласования с центром.
- Никакие персональные данные и секреты не хранятся в клиентском коде.
